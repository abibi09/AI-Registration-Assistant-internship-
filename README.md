## Project Overview

AI Registration Assistant is a Python-based chatbot designed to help students complete internship registration.

The assistant interacts with students, understands their queries, collects registration information, validates the entered details, and confirms the registration.

## Features

- Greeting and introduction
- Internship registration
- User information collection
- Intent recognition
- Entity extraction
- Email validation
- Name validation
- Registration confirmation
- Registration ID generation
- Date and time recording
- JSON-based data storage
- Help and eligibility information
- Exit option
